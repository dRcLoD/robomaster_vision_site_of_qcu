# 写在最前面的话

![竟然因为这种事情在烦恼](/images/preface-1.jpeg)

![一味地烦恼是找不出答案的](/images/preface-2.jpeg)

你都来青岛城市学院了，都知道你什么水平，也知道你啥也不会。再问这种我跟不跟得上来不来得及的问题自己扇自己嘴巴子。

学会提问。不要问“为啥我的代码报错？应该怎么解决”应该问“我在实现 xx 功能时，出现了如下报错。部署平台为 xx，环境为 xx，相关代码如下，请问应该如何解决？”

（还不会的话去阅读：[《提问的智慧》](https://github.com/ryanhanwu/How-To-Ask-Questions-The-Smart-Way/blob/main/README-zh_CN.md)）

学会用 AI。不是让你用 nc 豆包，是要学会使用 agent 帮你写代码。比如 codex、workbuddy。没人管你你的代码是不是 AI 写的或者 ai 率多少，但是你的代码得能跑，你知道他怎么跑的，并且出问题了你会改。

学会翻墙，这个没法教。教了我得进局子。
