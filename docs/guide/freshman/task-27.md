你需要学习：

1. **C 语言**。如果不知道怎么学，你可以看：[C 语言教程](https://www.bilibili.com/video/BV1U44y1y7xN)。

   你需要掌握的 C 语言知识：数据类型，常量变量，作用域和声明周期，选择结构，循环结构，判断结构，数组，指针，结构体。

2. **opencv**。如果不知道怎么学，你可以看：[opencv 教程](https://www.bilibili.com/video/BV1QS4y1J76n)。

   你需要掌握的 opencv 知识：Mat 类型，一些常见的图像处理。

3. **yolo**。这个不用学，可以看：[yolo 教程](https://www.bilibili.com/video/BV1bg4y1R7cs?)。

   知道怎么训练怎么推理就行。
